# 快捷键

在 **设置 → 快捷键** 中按分类查看、搜索和修改键位，也可以只显示已绑定的动作。

| 分类 | 支持的动作 |
| --- | --- |
| 划词 | 显示动作条、解释、翻译、润色、订正、存笔记、续入或新建快速会话，以及自定义划词动作 |
| 截图 | 进入截图模式、OCR、贴图、复制截图、截图问 AI、截图翻译 |
| 笔记 | 新建便签、新建普通笔记、打开笔记库、显示或隐藏全部便签 |
| 聊天 | 快速提问、新建聊天、复制当前会话最近的已完成回复 |
| 系统 | 主窗口显隐、设置、窗口置顶、暂停或恢复快捷键、快捷键速查、自动划词浮标开关 |

## 生效范围

- **划词动作**：每次按键都重新确认前台应用当前有选中文字，没有选区时静默忽略。不会复用上次选区，也不会为了试探选区发送 `Ctrl+C`。系统无法确认选区的自绘控件等应用中，划词快捷键不响应；仍可使用现有鼠标划词动作条及其取词兜底。
- **截图动作**：OCR、贴图、复制和识图快捷键只绑定到截图窗口，必须先进入截图模式并框选区域。截图窗口隐藏、关闭、尚未框选、正在识字或编辑标注文字时，这些动作不执行。进入截图模式本身是全局入口，默认 `Ctrl+Alt+A`。
- **笔记、聊天和系统动作**：全局生效；截图期间暂停这些全局绑定，结束截图并松开修饰键后恢复，避免一次按键误触两个动作。

划词翻译、润色和订正仍先显示结果，由用户确认是否替换原文。截图问 AI 和截图翻译仍先将图片及提示词填入会话，等待手动发送。OCR 保持本地识字流程。

## 配置与恢复

- 内置动作预设默认快捷键，可直接使用或手动修改。已有自定义键位和已清除的绑定会保留；默认键位与已有绑定冲突时不自动启用。续入、新建快速会话及用户自定义划词动作可按需设置。
- “清除”表示停用该绑定，不会回退到默认键位。“恢复本类默认”只恢复当前分类的默认键位。
- 修改键位时，在当前设置窗口按下组合键即可；`Esc` 取消，8 秒未输入自动取消。录制不会在后台全局吞键。
- 应用会统一修饰键别名和顺序，阻止生效范围重叠的重复键位，保留系统及截图撤销、重做键位。截图局部动作可与截图期间已暂停的全局动作使用相同组合键。
- 自定义划词动作出现在同一分类中；删除动作后，其快捷键不再注册。
- 托盘菜单提供“暂停全局快捷键”和“恢复全局快捷键”。暂停期间，已配置的暂停/恢复键始终保留；即使未配置恢复键，也能从托盘恢复。
- 托盘“快捷键速查”按分类展示已绑定动作和键位。注册失败会在设置保存时提示；其他软件的快捷键冲突不一定能被完全预判，修改后应在实际使用的应用中试按。

新建或隐藏全部便签不会删除笔记；批量隐藏前会保存便签内容，并保留固定状态，之后可恢复显示。
