# 桌面便签

## 创建与管理

- 默认按 Ctrl+Alt+N 新建便签，立即保存到笔记库的“便签”页。
- 标题栏“+”新建，“…”打开分类菜单，“×”保存并隐藏。双击标题重命名。
- 隐藏不删除便签，重启后仍保持隐藏；从托盘“便签管理”或笔记库重新显示。
- 同一张便签只打开一个浮窗，正文在浮窗和笔记库间同步；切换编辑入口时先保存。
- 删除进入回收站。恢复后原内容和附件保留，提醒保持暂停。

## 编辑与待办

右键“插入”可添加待办、图片、分隔线和日期；“格式”提供加粗、斜体、下划线、删除线、字体、文字颜色、对齐和清除格式。选中文字不弹出格式工具条。

- 点击待办左侧方框切换完成状态；完成项加删除线。
- Enter 继续下一项，空白项再次 Enter 退出待办；Tab / Shift+Tab 调整层级。
- 选中多行后可一起转为待办；“显示 → 折叠已完成项”只折叠显示，不删除内容。
- 复制内容和文本导出使用可读文字，以 [ ] / [x] 保留待办状态。
- 粘贴或拖入本地图片会复制到应用附件目录。远程图片不会自动联网下载。

## 外观与显示

每张便签独立保存纸色、不透明度、尺寸、位置、置顶、锁定、收起及可见状态。提供六种纸色、自定义色和跟随主题；不透明度为 70%–100%。

“显示 → 锁定编辑”防止误改，菜单仍可解锁。收起只隐藏正文，再展开恢复原高度。贴边隐藏默认关闭，开启后支持屏幕顶部、左边和右边；悬停展开，离开后收回，输入、菜单和拖动期间不收回。相邻显示器的内部接缝不作为隐藏边缘。显示器变化时将窗口移回可见范围。

## 本地提醒

右键“添加提醒…”设置时间；支持单次、每天和每周，每周可选多个星期。已有规则时显示“管理提醒…”，可暂停、修改或删除。时间按本地时区计算，界面预览下一次时间。

- 到时显示提醒卡片，可打开便签、关闭卡片或延后 10 分钟。
- 隐藏便签也会提醒；重复提醒不会重置清单勾选状态。
- Nemo 必须保持后台运行；退出应用后不唤醒系统。重新启动或恢复睡眠后，错过的提醒合并提示一次，不逐次补弹。
- 移入回收站即停用提醒，恢复后需要手动重新启用。
- 不调用 AI、无需网络，不提供跨设备同步。

## 模板与导出

“新建便签 → 模板”提供今日清单、会议记录和购物清单，也可从剪贴板创建。在“更多”中保存自定义模板、复制便签或导出 TXT / PNG。

模板保留正文和外观，已完成项重置为未完成，不复制提醒或桌面位置。复制便签保留内容，但不复制活动提醒。图片导出包含完整正文，超长便签请改用文本导出。

笔记库“便签”页可按桌面显示、已隐藏、带提醒和未完成待办筛选，并批量显示、隐藏、修改纸色或移入回收站。
