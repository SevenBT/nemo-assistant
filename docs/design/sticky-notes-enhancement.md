# 便签模块增强方案

状态：已按确认范围实现，完成自动化回归与离屏界面检查；Windows 实际桌面交互仍需人工验收。日期：2026-11-13。

## 已确认的方向

- 普通便签中直接插入可勾选待办项，正文、图片和清单可以混排。
- 提醒支持指定时间、每天重复和每周重复。
- 本次完善本地便签，不加入跨设备同步。
- 延续简洁界面：常用操作直接可见，其余放入分类子菜单，不堆解释文字。

## 改版前的实现与缺口

根据 `app/ui/sticky_note_window.py`、`app/ui/sticky_note_controller.py`、`app/ui/notes_dialog.py`、`app/core/note_manager.py` 和 `app/core/scheduler.py` 的实际实现：

- 已有可编辑浮窗、拖动、缩放、内容防抖保存、位置保存、置顶切换、隐藏和删除。笔记库已有便签分类、搜索、复制副本、TXT 导出和回收站。
- 标题栏右键与正文右键菜单不同，功能入口分散。标题栏双击会关闭浮窗；关闭还涉及取消桌面固定，与隐藏不一致。
- 背景颜色按创建顺序循环，缺少用户选择与逐张持久化；尺寸、置顶等显示状态也未形成完整的恢复机制。
- 数据模型虽有待办、日期、重复等字段，但当前便签浮窗没有可勾选清单或提醒设置界面。不能据此认为这些功能已经完成。
- 已有 APScheduler 定时任务基础和提醒工具，但没有与具体便签绑定的提醒流程。
- 已有主窗口顶部贴边隐藏逻辑，不能直接视为便签已经支持贴边。

## 推荐右键菜单

标题栏和正文共用便签操作。正文存在选区时，前置剪切、复制、粘贴等标准编辑操作；避免两套菜单能力不一致。主菜单建议保持约十项：

```text
新建便签       ›  空白 / 从剪贴板 / 从模板
添加提醒…         已有提醒时改为“管理提醒…”
────────────────
插入           ›  待办项 / 图片 / 分隔线 / 日期时间
格式           ›  加粗 / 斜体 / 下划线 / 删除线 / 字体 / 对齐
外观           ›  纸张颜色 / 不透明度 / 默认尺寸 / 恢复外观
显示           ›  置顶 / 收起正文 / 锁定编辑 / 贴边隐藏
────────────────
便签管理
更多           ›  复制便签 / 导出 / 保存为模板
────────────────
隐藏便签
移入回收站
```

菜单文案简短，不显示重复的范围说明。勾选状态仅用于置顶、锁定等实际开关。选中文字不弹出工具条，格式操作从右键进入。

## 便签交互

### 编辑与保存

- 默认单击正文直接编辑，双击标题重命名；删除现有“双击标题关闭”的行为。标题栏仅保留新建、菜单、隐藏等少量入口。
- 标题栏的关闭图标语义统一为“隐藏便签”：保存后隐藏，不删除、不取消桌面展示资格。隐藏状态在重启后保留；从管理页或托盘重新显示。
- 自动保存继续防抖；失焦、隐藏、退出前补做保存。必要时短暂显示“保存失败”，不要常驻大段状态文案。
- 保持便签富文本与普通笔记 Markdown 分离。复制和 TXT 导出输出可读文字；不得再次把 Qt HTML 标签显示为正文。
- 图片粘贴与拖入后复制到应用管理的本地附件目录，避免依赖临时剪贴板或外部文件路径；通过回收站恢复后仍可显示。

### 待办

- 在当前光标插入复选框，支持普通段落和清单混排；选中多行可批量转为待办。
- Enter 新增下一项，空白待办再次 Enter 退出；Tab / Shift+Tab 调整层级。
- 勾选后文字变淡并加删除线；默认保留原位置，不自动重排，避免编辑内容跳动。
- 可折叠已完成项，重新打开或重启后仍能还原勾选状态。
- 第一版提醒绑定整张便签，逐项待办提醒暂不纳入。重复提醒不自动取消勾选或重置整张清单。

### 外观与窗口

- 六种低饱和纸色，提供跟随主题和自定义色；独立保存每张便签的选择，自动适配可读文字颜色。
- 字体、字号、重点文字颜色和清除格式；不透明度限制为 70%–100%。
- 置顶、只读锁定、收起正文到标题栏。锁定仅防误编辑，菜单仍可解锁和隐藏。
- 保存位置、尺寸、屏幕、置顶、折叠、可见状态及外观；显示器断开或缩放改变后将窗口恢复到可见范围。
- 贴边隐藏支持顶部、左侧、右侧；默认关闭。拖到对应边缘后留下小标签，悬停展开，离开后收回。正在输入、打开菜单或拖动时不收回；不处理多屏之间的内部接缝。

### 提醒

- 便签提醒对话框包含日期、时间、重复规则和可选提示音；每周重复可选择星期。采用用户本地时区，界面显示下一次提醒时间。
- 每张便签第一版保留一组提醒规则，可修改、暂停或删除；支持“10 分钟后再提醒”。
- 到时显示桌面提醒卡片，点击打开对应便签；隐藏便签照常提醒，编辑或查看不自动停止重复规则。
- 移入回收站立即停用提醒；恢复便签时提醒保持暂停，防止意外再次触发。
- 第一版本机应用退出后不后台唤醒系统。重启、恢复睡眠后，把错过的提醒合并提示一次，不连续弹出历史提醒。
- 提醒规则明确设置，不经 AI 推测，不需要模型或网络调用。

### 管理与模板

- 复用笔记库的“便签”页，不另建一个独立管理器。
- 增加桌面显示、已隐藏、带提醒、含未完成待办等筛选；列表显示纸色和上次修改时间，提醒和待办进度放在悬停提示中。
- 可批量显示、隐藏、修改纸色、移入回收站；删除采用可恢复流程，彻底删除仍放在回收站。
- 内置空白、今日清单、会议记录、购物清单模板；“保存为模板”保留正文结构和外观，不复制提醒规则、完成状态或桌面位置。
- 更多菜单提供复制副本、导出 TXT / PNG；复制副本同样不复制活动提醒。

## 实现分期

1. **基础体验**：统一菜单与隐藏语义，重命名、格式、颜色、窗口状态持久化、待办混排，以及笔记库和浮窗同步。
2. **提醒与管理**：单次 / 每天 / 每周提醒、延后、遗漏合并、筛选与批量操作。提醒是本次确认范围，分期不表示取消。
3. **桌面效率**：贴边隐藏、折叠、模板、图片附件可靠性和 PNG 导出。

后续可选：选中文字后的 AI 润色、翻译和提取待办。仅预览结果，经用户确认再替换；本轮不作为前置依赖。

## 实现约束

- 统一由便签控制器维护以 note_id 为键的浮窗注册表，移除笔记库与控制器两套窗口所有权，确保每张便签最多一个浮窗。
- 在笔记数据库中增加便签显示配置和提醒关联，使用增量迁移；原有内容和主键不变。便签存储格式需要明确版本，避免混淆普通 Markdown 和富文本。
- 两处编辑器共用便签编辑组件及清单序列化逻辑；同步外部更新时不覆盖尚未保存的本地编辑，不因重载丢失光标与待办状态。
- 复用 APScheduler 的定时能力，便签使用专用回调；SQLite 提醒记录作为配置来源，调度实例由记录重建，避免和 jobs.json 出现两份真值。
- 保存内容与修改外观、标签、提醒相互独立，避免通用 update 的默认参数意外清空提醒或其他元数据。
- 默认本地保存，不增加同步登录、订阅或会员入口。

## 验收重点

- 热键新建、笔记库新建及复制副本，类型正确并且立即可见；同一便签不会重复打开浮窗。
- 纯文字、富文本、图片和待办在浮窗与笔记库中往返编辑，均不出现 HTML 源码或内容覆盖。
- 隐藏 / 显示 / 重启后内容、外观、勾选状态和窗口状态一致；显示器变化后仍能找回窗口。
- 提醒在隐藏、重复、延后、删除、恢复、睡眠和重启时按上述规则运行；离线可用，不调用模型。
- 贴边不会在编辑、菜单操作或多屏内部边界意外收起。
- 深浅主题、高 DPI 和较窄便签下，正文、菜单及提醒设置可读可用。

本轮实现了菜单、混排待办、显示状态、提醒、管理筛选、模板和导出；使用方法见 [便签说明](../zh/sticky-notes.md)。数据库使用新增表保存配置，原有便签内容和主键保留。自动化验证使用临时数据库，不改动用户便签。多屏物理断连、真实桌面悬停以及系统睡眠唤醒仍需 Windows 人工验收。
